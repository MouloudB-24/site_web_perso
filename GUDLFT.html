GÜDLFT - Application Web Python

Le projet GÜDLFT consiste à améliorer une plateforme destinée aux clubs locaux pour organiser des compétitions de force. Le but est de corriger les bugs du prototype existant et d'assurer la fiabilité et la performance de l'application avec des tests rigoureux.

Problèmes résolus:

  • Correction des bugs du prototype (erreurs de syntaxe, exceptions non gérées).
  • Optimisation des performances et réduction des temps de réponse.
  • Mise en place d'une gestion efficace des erreurs et des messages clairs.
  • Implémentation de tests unitaires et d'intégration pour éviter les régressions.
  • Refonte et amélioration de l'organisation du code pour une meilleure maintenabilité.
  • Tests de compatibilité sur différents navigateurs et appareils.
  • Prise en compte des retours utilisateurs pour améliorer les fonctionnalités.

Technologies utilisées:

Python Flask pytest Selenium TDD Locust Git
