Développez une application Web en utilisant Django

En tant que Lead Développeur Python au sein de la start-up LITRevu, j'ai développé une application web complète utilisant le framework Django. Cette plateforme permet aux utilisateurs de demander et publier des critiques de livres, avec des fonctionnalités robustes d'authentification, de gestion des flux d'activité et d'abonnements entre utilisateurs.

Problèmes résolus :

  • Développement d'un système d'authentification sécurisé contre les attaques par injection.
  • Création d'une interface utilisateur intuitive et accessible pour une navigation fluide.
  • Optimisation des interactions avec la base de données pour garantir l'intégrité et les performances.
  • Implémentation d'un flux d'activité dynamique affichant les critiques et tickets des utilisateurs suivis.
  • Conception évolutive permettant de gérer un nombre croissant d'utilisateurs sans impact sur les performances.
  • Mise en place de tests rigoureux pour assurer la stabilité et la fiabilité de l'application.

Technologies utilisées :

Python Django HTML/CSS JavaScript SQLite Git GitHub Responsive Design
