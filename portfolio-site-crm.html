CRM Logiciel

The internal CRM software helps manage clients, contracts, and events for an association. Moving it from a CLI to a web application makes it more accessible and user-friendly for all teams (Sales, Support, Management).

Problems solved:

  • Improving accessibility by providing a web-based interface.
  • Simplifying CRUD operations with an intuitive dashboard.
  • Enhancing real-time collaboration and data visibility.
  • Securing user authentication and data access through JWT.
  • Monitoring and logging errors with Sentry.

Technologies utilisées:

Python Flask SQLAlchemy Flask-Migrate MySQL JWT Sentry Docker GitHub Actions
