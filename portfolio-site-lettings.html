Orange County Lettings - Application Django

Cette application web a pour objectif d'améliorer la performance et la maintenabilité d'une plateforme de location immobilière. Le projet consiste à refactoriser l'application Django en adoptant une architecture modulaire pour une meilleure organisation et réduction de la dette technique.

Problèmes résolus :

  • Réduction de la dette technique en restructurant le code.
  • Amélioration de la couverture des tests avec un objectif de 80%.
  • Ajout de documentation claire avec Sphinx et Read The Docs.
  • Création de pages d'erreur personnalisées (404 et 500).
  • Surveillance des erreurs avec Sentry.
  • Mise en place d'un pipeline CI/CD avec GitHub Actions.
  • Optimisation des performances pour assurer la scalabilité.

Technologies utilisées :

Python Django MySQL Sentry Sphinx Read The Docs Docker GitHub Actions
