SoftDesk API RESTful

SoftDesk est une application B2B permettant de remonter et suivre les problèmes techniques via une API RESTful sécurisée. Conçue avec Django REST Framework, cette API respecte les normes OWASP et RGPD, garantissant la protection des données et une architecture durable.

Problèmes résolus :

  • Renforcement de la sécurité des données utilisateur (normes OWASP, RGPD).
  • Gestion avancée des permissions et des accès.
  • Validation stricte des entrées pour éviter les vulnérabilités.
  • Optimisation des performances avec pagination et requêtes efficaces.
  • Implémentation de tests automatisés pour éviter les régressions.
  • Documentation claire et détaillée pour faciliter l'utilisation de l'API.

Technologies utilisées :

Python Django REST Framework Postman OAUTH2 Git GitHub OWASP RGPD Green Code
